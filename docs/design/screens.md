# Screen specifications • proposed for approval
Read DESIGN.md first. O = direct composition from original board; E = extrapolation. The supplementary mockup illustrates the four E screens. Written behavior and accessibility requirements govern interactions.

|Surface and basis|Phone • reading order and artwork|Desktop • composition|States|
|---|---|---|---|

|Sign-up E • sign-in + confirmation pattern|Small illustrated strip then Create account, required identity/email/password fields, submit, sign-in link. |Onboarding O • middle panel|Three progress marks with text Step n of 3.
